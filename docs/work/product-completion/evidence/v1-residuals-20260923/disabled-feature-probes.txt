# W17-39 (R-16) — how each forge answers a list for a feature switched OFF. Live probes, 2026-09-23.

## GitHub (anonymous, api.github.com)
torvalds/linux  has_issues=False   GET /repos/torvalds/linux/issues?state=all&per_page=1  -> HTTP 200 []
git/git         has_issues=False   GET /repos/git/git/issues?state=all&per_page=100       -> HTTP 200, 100 items, all 100 carry `pull_request` (PRs only)
torvalds/linux                     GET /repos/torvalds/linux/issues/1                    -> HTTP 410
=> the LIST never errors; only repo metadata (has_issues) distinguishes "disabled" from "no issues".
   (The residual note on W17-35 guessed 410 for the list; that is the single-issue answer only.)
