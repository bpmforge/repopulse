## 3. Horizontal overflow — FACT at 390/768/1440 and at 200% on 768/1440; RESIDUAL at 390 × 200%

`overflow.jsonl`, 168 rows: 28 paths (18 screens + 10 repo tabs) × 3 widths ×
2 zooms. Zoom is emulated the way a browser does it (CSS viewport halved,
deviceScaleFactor doubled). Measured on the document AND on `<main>`, because
the shell root is `overflow-hidden` and the document alone can never report it.

| Viewport | CSS px | Paths with sideways scroll |
|---|---|---|
| 390 × 100% | 390 | **0 / 28** |
| 768 × 100% | 768 | **0 / 28** |
| 1440 × 100% | 1440 | **0 / 28** |
| 768 × 200% | 384 | **0 / 28** |
| 1440 × 200% | 720 | **0 / 28** |
| 390 × 200% | 195 | 14 / 28 — residual, 16–129 px inside `<main>` |

Against the RP-01 baseline at 390: the Settings tab strip pushed `<main>`
440 px wide of the viewport, the repository tab strip 292 px, the Reviews
table 272 px (visible in `baseline/mobile-390x844/05-findings.png` as the file
column cut mid-word). Working-tree fixes: both tab strips now scroll within
themselves (`overflow-x-auto`, `shrink-0 whitespace-nowrap`), and the findings
table sits in its own scrolling wrapper. All three are 0 px now.

**The 390 × 200% residual is declared, not hidden.** A 195 CSS-px viewport is
125 px below the 320 px floor WCAG 1.4.10 (reflow) is written against and
narrower than any device this product is specified for; the acceptance
criterion's "including at 200% zoom" is met at 768 and 1440, and at 390 the
measurement is `test.fail`-marked as expected so it keeps running and must be
un-marked on purpose the day it passes. The 14 paths and their pixel counts are
in the jsonl. Fixing them means redesigning the KPI tiles, the identities and
agreements tables, and the repo sub-tab cards for a sub-200-px column, which is
outside this ticket's "do not redesign" scope.

## Spec defect fixed during this run

The first 2026-09-11 run reported 2 failures with every assertion green: the
empty-state route handler called `route.fetch()` on the server-sent events
stream, which never completes, and threw "Test ended" at teardown — once
attributed to the narrow-layout axe test that never used the handler. The
handler now lets `/api/v1/events` through and each routed test ends with
`unrouteAll({ behavior: 'ignoreErrors' })`. Rerun: 22/22.
